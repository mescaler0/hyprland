# My Hyprland Dotfiles

Beautiful and functional Hyprland setup with dynamic theming using wallust.

![Screenshot](screenshot.png)

## Features

- 🎨 **Dynamic theming** with wallust (colors change based on wallpaper)
- 🖼️ **Wallpaper selector** with live previews (SUPER+W)
- 📊 **Waybar** with custom styling and icons
- 🚀 **Rofi** launcher with Tokyo Night theme
- 🔒 **Hyprlock** + **Hypridle** for screen locking
- 🎭 **Tokyo Night** GTK theme
- 📁 **Yazi** terminal file manager
- 💻 **Kitty** terminal with custom config
- 🔔 **Dunst** notifications themed to match wallpaper

## Quick Install
```bash
git clone https://github.com/YOUR_USERNAME/dotfiles.git ~/dotfiles
cd ~/dotfiles
chmod +x install.sh
./install.sh
```

Logout and select Hyprland from SDDM login screen.

## Manual Install

### Prerequisites

Arch Linux with base-devel and git installed.

### Installation
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/dotfiles.git ~/dotfiles
cd ~/dotfiles

# Install packages
sudo pacman -S --needed - < nativelist.txt
yay -S --needed - < aurlist.txt

# Stow configurations
stow hyprland waybar rofi kitty dunst wallust scripts hypridle hyprlock zsh nvim
```

## Package Lists

- **nativelist.txt** - Official Arch repo packages
- **aurlist.txt** - AUR packages
- **pkglist.txt** - All explicitly installed packages

## Keybindings

| Key | Action |
|-----|--------|
| `SUPER + Return` | Terminal (Kitty) |
| `SUPER + D` | App launcher (Rofi) |
| `SUPER + W` | Wallpaper selector |
| `SUPER + Q` | Close window |
| `SUPER + L` | Lock screen |
| `SUPER + F` | Toggle fullscreen |
| `SUPER + Space` | Toggle floating |
| `SUPER + N` | Minimize window |
| `SUPER + 1-9` | Switch workspace |
| `SUPER + SHIFT + 1-9` | Move to workspace |
| `SUPER + Mouse` | Move/resize window |
